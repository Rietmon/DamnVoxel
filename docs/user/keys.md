# Keys

This is the default layout. **☰ → Keys and mouse** changes any key, switches between the MagicaVoxel, Blockbench and Blender layouts and saves your own to a file. Ctrl on a Mac is Cmd.

## General
| Keys | What |
|---|---|
| Ctrl+K, F1 | all commands |
| Ctrl+Z / Ctrl+Shift+Z, Ctrl+Y | undo / redo |
| Ctrl+S / Ctrl+Shift+S | save / save as |
| Ctrl+O | open |
| Ctrl+E | export mesh |
| Ctrl+Alt+N / Ctrl+Alt+W | new document / close tab |
| Alt+PageUp / Alt+PageDown | neighbouring tab |
| Tab | Model ↔ Scene mode |
| ` | radial menu |
| Shift+\ | hide interface |

## Camera and view
| Keys | What |
|---|---|
| F / Home | frame the model / the whole scene |
| Numpad 1, 3, 7 (Alt+1, 3, 7) | front, right, top; with Ctrl — from the other side |
| Numpad 5 (Alt+5) | perspective / orthographic |
| Ctrl+Numpad 5 (Alt+0) | isometric |
| Shift+Z | shading: lit / flat / clay |
| Alt+S, Alt+↑ / Alt+↓ | slice, up / down |

## Tools
| Keys | What |
|---|---|
| A / E / P | add / erase / paint |
| V, Shift+V, G | brush, stamp, sculpt |
| X | face |
| B, L, R, O, S, C | box, line, rectangle, ellipse, sphere, cylinder |
| Shift+S | smooth shapes (SDF) |
| J / Shift+J | curve / rope |
| I, Shift+P, Shift+F | eyedropper, replace color, fill |
| [ ] , 1…9 | brush size |
| Q / Shift+Q | brush shape / brush mode |
| Alt+B | stamp from the selection |
| Alt+L | color lock |
| Shift+M, Alt+M | mirror: through a voxel center or between; at the model center |

## Selection
| Keys | What |
|---|---|
| M, K, U, W | rectangle, lasso, box, magic wand |
| T | move the selection |
| Ctrl+A / Ctrl+D / Ctrl+I | all / none / invert |
| Ctrl+] / Ctrl+[ | grow / shrink |
| Ctrl+C / Ctrl+X / Ctrl+V | copy / cut / paste |
| Ctrl+J, Delete | duplicate, delete |
| Alt+C | voxels of the chosen colors |
| Ctrl+Alt+S | remember a set |
| Ctrl+Shift+E | move into an object |

## Scene and palette
| Keys | What |
|---|---|
| Shift+N | new object |
| Ctrl+G / Ctrl+Shift+G | group / ungroup |
| End | put on the ground |
| Alt+D | linked copy |
| . / , | neighbouring color of the ramp |
| Shift+. / Shift+, | the same place in the neighbouring ramp |

## Animation
| Keys | What |
|---|---|
| Alt+A | timeline |
| Alt+/ | play / stop |
| Alt+. / Alt+, | next / previous frame |
